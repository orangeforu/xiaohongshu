# PRD: 小红书 AI 自动化内容创作平台

> **项目代号**: AutoXHS
> **目标**: 12个月内达到 10W 粉丝
> **创建日期**: 2026-05-07
> **赛道**: 情感分析 / 两性关系相处案例分享
> **状态**: Draft

---

## 1. 背景与目标

### 1.1 背景

- 用户已在小红书平台进行手动内容创作，积累了一定数量的博文和粉丝
- 内容创作耗时耗力，需要学习文案、配图、排版、发布时间优化等多维度技能
- 希望借助 AI 自动化能力，实现规模化内容产出，加速粉丝增长

### 1.2 核心目标

| 指标 | 当前状态 | 年度目标 | 里程碑 |
|------|---------|---------|--------|
| 粉丝数 | **859** | **100,000** | Q1: 5K / Q2: 20K / Q3: 50K / Q4: 100K |
| 月均发文量 | ~49篇（累计） | 60-90篇（日更2-3篇） | Q1起达到稳定日更 |
| 总获赞和收藏 | **20,000** | 单篇均赞500+ / 收藏200+ / 评论50+ | 持续优化 |
| 单篇平均获赞藏 | ~408（20000/49） | 700+ | Q3起稳定 |
| 爆款率（>1000赞） | TBD | >15% | Q3起稳定 |

### 1.3 关键假设

1. 账号当前无违规/限流状态
2. 情感/两性关系赛道适合高频更新，读者群体广泛
3. AI 生成内容能通过平台原创检测（需要人类审核环节）
4. 用户提供 49 篇历史博文用于 AI 风格学习
5. 创作者每天投入约 2 小时用于审核和发布

## 4. 功能详细设计

### 4.1 Phase 1: 内容学习与账号分析（第1-2周）

#### 4.1.1 数据采集模块

**功能描述**: 从创作者后台和已有博文中采集数据，建立账号画像

| 数据项 | 采集方式 | 用途 |
|--------|---------|------|
| 历史博文（标题、正文、标签） | 手动导出 / 截图 OCR / 网页爬取 | 训练风格模型 |
| 博文配图 | 下载保存 | 分析视觉风格 |
| 互动数据（赞、藏、评、浏览） | 创作者后台数据页面 | 评估内容效果 |
| 粉丝画像（性别、年龄、地域） | 创作者后台 | 定位受众 |
| 竞品账号内容 | 公开页面爬取 | 赛道对标分析 |
| 赛道热门话题 | 小红书搜索/热榜 | 内容选题 |

**输出产物**:
- `profile.json` — 账号画像（风格关键词、语气、常用结构、高互动内容模式）
- `style_guide.md` — 内容风格指南（供 AI 参考）
- `benchmark.md` — 赛道竞品分析报告

#### 4.1.2 账号定位分析

**自动分析内容**:

1. **内容赛道识别**: 通过历史内容 NLP 分类，确定主赛道和细分赛道
2. **爆款内容解构**: 分析高互动内容的共同特征（标题结构、字数、配图风格、发布时间）
3. **人设提取**: 从历史内容中提取 "作者人设"（专业度、亲和力、幽默感等维度）
4. **内容缺口分析**: 对比赛道热门内容，找出用户尚未覆盖但有潜力的选题方向

**输出产物**:
- `positioning_report.md` — 账号定位报告
- `content_gap_analysis.md` — 内容机会分析

### 4.2 Phase 2: AI 内容创作管线（第3周起持续）

#### 4.2.1 选题引擎

**功能**: 自动生成/推荐每日选题

```
输入: 赛道关键词 + 热点数据 + 历史互动数据 + 内容缺口
  │
  ├─ 热点追踪: 抓取小红书/微博/抖音同赛道热点
  ├─ 常青内容: 基于关键词生成 evergreen 选题
  ├─ 系列规划: 自动生成内容系列（如"XX的100个技巧"）
  └─ 排期表: 输出未来30天的内容日历
  │
输出: 选题列表（标题方向 + 预期互动区间 + 优先级）
```

#### 4.2.2 文案生成

**功能**: 根据选题生成完整小红书博文

| 模块 | 说明 |
|------|------|
| **标题生成器** | 生成 3-5 个标题选项，应用爆款标题公式（数字、悬念、痛点、对比等） |
| **正文生成器** | 根据 style_guide 生成 300-800 字正文，包含 emoji、分段、关键信息突出 |
| **标签生成器** | 生成 10-15 个话题标签，混合热门+精准长尾标签 |
| **封面文案** | 生成封面图上的文字内容 |
| **评论区运营** | 生成置顶评论和互动引导话术 |

**生成流程**:

```
选题 → 标题(5 options) → 用户确认/自动选择
                    ↓
              正文草稿生成
                    ↓
         自我审核(合规、质量、风格匹配)
                    ↓
              优化迭代(1-2轮)
                    ↓
              最终文案 + 标签 + 封面文案
```

#### 4.2.3 图片生成

**功能**: 生成封面图和配图

| 场景 | 方案 |
|------|------|
| 封面图 | 使用 AI 图片生成（DALL-E / Midjourney / 本地 SD）或模板系统 |
| 配图 | 根据内容生成/检索相关配图 |
| 文字图 | 知识卡片、清单、对比图等，使用程序化排版 |
| 风格一致性 | 建立视觉模板，保持封面风格统一 |

**封面图模板库**（按赛道预置）:

```
templates/
├── list_style/          # 清单式（10个XX / 必看的XX）
├── tutorial/            # 教程式（步骤123）
├── before_after/        # 对比式
├── quote/               # 金句/观点式
├── data_visual/         # 数据可视化
└── personal/            # 个人分享式
```

#### 4.2.4 内容审核

**自动化审核检查**:

- [ ] 敏感词/违禁词检测（广告法、平台规则）
- [ ] 内容原创度检测
- [ ] 风格匹配度（与历史内容一致性）
- [ ] 信息准确性验证（事实核查）
- [ ] 字数/格式合规

### 4.3 Phase 3: 发布与数据闭环（第4周起）

#### 4.3.1 发布模块

**方案选择**:

| 方案 | 说明 | 风险 |
|------|------|------|
| **方案A: 半自动（推荐）** | AI 生成内容 → 用户审核确认 → 半自动发布 | 低风险，符合平台规则 |
| 方案B: 全自动 | API/RPA 自动发布 | 高风险，可能触发风控 |

**推荐工作流**:

```
AI 生成内容（文本+图片）
    ↓
推送到审核队列（Web Dashboard / 微信通知）
    ↓
用户审核（通过/修改/驳回）
    ↓
一键发布 / 定时发布
    ↓
记录发布数据，进入分析管线
```

#### 4.3.2 数据分析与优化

**采集指标**:

- 每篇博文的浏览、点赞、收藏、评论、转发数据
- 粉丝增长趋势（日/周/月）
- 内容表现排名（TOP/底部内容）
- 最佳发布时间段

**优化策略**:

```
数据反馈 → 分析哪些内容类型表现好
         → 调整选题权重（多产高互动类型）
         → 优化标题公式
         → 调整发布时间
         → 更新风格指南
         → 下一轮内容质量提升
```

**周报自动生成**:

```
📊 本周内容报告
- 发文 X 篇，新增粉丝 Y
- 爆款内容 TOP3: ...
- 下周建议: ...
- 赛道热点: ...
```

### 6.2 10W 粉丝增长策略

**数学模型**:

```
当前基准:
- 49篇发文 → 20,000获赞和收藏 → 平均408赞/篇
- 859粉丝 → 粉丝转化率约 4.3%（859/20000，粗略估算）
- 这个均值在情感赛道属于中上水平，说明内容有潜力

假设:
- 日均发文 2-3 篇（2小时审核时间可支撑）
- 平均单篇涨粉 = 8-15 粉丝/篇（基于408均赞的基础）
- 月发文量 = 60-90 篇
- 爆款带动效应：一篇万赞内容可带来500-2000粉丝

则:
- 基础月涨粉 = 60 × 10 = 600 + 爆款带动 + 自然增长
- 第3个月起需有稳定爆款产出（月均2-3篇万赞）
- 第6个月需出现破圈内容（5万赞以上）

关键杠杆:
1. 情感共鸣 → 收藏率高 → 算法长尾推荐
2. 案例故事化 → 评论区讨论 → 互动率飙升
3. 系列化内容 → 粉丝粘性 → 复访率
4. 热点+情感 → 借势流量（如节日、社会事件情感解读）
5. 评论区运营 → 私信咨询 → 粉丝忠诚度
```

**增长飞轮**:

```
情感共鸣内容 → 高收藏/评论率 → 算法长尾推荐（可持续数周）
    → 更多曝光 → 更多粉丝关注
    → 粉丝有情感困扰 → 主动互动/私信 → 社区氛围增强
    → 评论区真实故事分享 → 内容素材反哺
    → 正循环
```

## 7. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| AI 内容被平台检测为不原创 | 中 | 高 | 人工审核 + 风格强匹配 + 加入个人化细节 |
| 账号限流/封号 | 低 | 极高 | 半自动发布、控制频率、遵守平台规则 |
| 情感话题敏感度过高 | 中 | 中 | 避免极端观点、保持价值观中立、不站队 |
| 同质化竞争严重 | 高 | 中 | 案例差异化、真实故事包装、独特视角 |
| AI 生成内容质量不稳定 | 中 | 高 | 多轮审核 + 质量评分 + 持续优化 prompt |
| 粉丝增长不及预期 | 中 | 高 | 及时调整选题策略、加大热点话题比例 |
| 平台规则变化 | 中 | 中 | 持续关注平台公告、灵活调整策略 |
