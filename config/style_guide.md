# 内容风格指南

> 赛道: 情感分析 / 两性关系相处案例分享
> 生成日期: 2026-05-07
> 状态: 初始模板（待分析49篇历史博文后更新）

## 内容定位

- **主赛道**: 情感分析
- **细分赛道**: 两性关系相处案例分享
- **目标受众**: 18-35岁，有情感困扰/恋爱关系问题的女性为主
- **人设关键词**: 温暖、专业、有洞察力、像闺蜜一样

## 内容结构模板

### 类型A: 案例故事型（占比40%）

```
标题: [痛点/悬念/数字] + [情感共鸣点]
  例: "结婚3年，他用一件事让我彻底安心"
  例: "那个从不说'我爱你'的男生，其实最爱你"

开头: 用一个具体场景/对话引入（1-2句话）
  例: "昨天收到一条读者私信，她说……"

正文:
  1. 讲述案例故事（具体、有细节）
  2. 分析问题本质（专业但不说教）
  3. 给出可操作的建议（1-3条）

结尾: 共鸣金句 + 互动引导
  例: "感情里，细节从来不会骗人。你呢？"

标签: #两性关系 #恋爱技巧 #情感共鸣 #关系经营 ...
```

### 类型B: 关系技巧型（占比30%）

```
标题: [数字] + [具体场景] + [结果承诺]
  例: "5个让感情保鲜的小习惯，越用越甜"

正文:
  1. 简短引入（为什么这个话题重要）
  2. 分点列出技巧（每点1-2段，口语化）
  3. 每个技巧配一个小案例/场景

结尾: 总结 + 鼓励
```

### 类型C: 观点金句型（占比15%）

```
标题: 一句话观点/反常识观点
  例: "好的感情，不是不吵架"

正文: 短文，300-500字，以观点为主，辅以简短案例
```

### 类型D: 热点解读型（占比15%）

```
标题: 热点事件 + 情感角度解读
  例: "XX离婚上热搜：这段关系里，3个细节早就说明了结局"

正文: 热点简述 + 情感专业分析 + 对读者的启发
```

## 语言风格

- **语气**: 温暖亲切，像和闺蜜聊天
- **人称**: 第一人称 + 第二人称（"你"）为主
- **emoji**: 适量使用（每篇5-10个），增加亲和力
- **段落**: 短段落（2-4行），空行分隔，方便手机阅读
- **禁忌**: 不说教、不居高临下、不极端化
- **金句**: 每篇至少1-2句可以被摘抄传播的金句

## 标题公式

1. **数字型**: "X个/种/招..."
2. **悬念型**: "其实.../真正.../没想到..."
3. **痛点型**: "为什么总是.../你是不是也..."
4. **对比型**: "不是...而是..."
5. **场景型**: "当他...的时候/那天..."
6. **反常识型**: "90%的人都错了/你以为...其实..."

## 封面风格

- **色调**: 温暖柔和（粉色、米白、浅紫）
- **文字**: 大号字体，突出核心信息
- **风格**: 简约、有质感、情感氛围
